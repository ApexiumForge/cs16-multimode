CoD:MW
41 classes, 48 perks. Team deathmatch.

PROGRESSION

Classes start at level 51. Each level gives 2 skill points. Every class saves its XP and stats. Honor is now called Gold; your balance is preserved.

SHOPS

/shop - cash shop: Red Bull, random perk, XP, healing and armor
/goldshop - choose a perk with Gold
/codshop - choose either shop
/sell - sell your perk for $2000 (confirmation)
/item - your perk description
Sell or drop your current perk before buying another.

COMMANDS

/cod - main menu
/class - choose class
/codclasses - class descriptions
/codstats - spend/reset skill points
/codreset - refund points
/items - perk catalogue
/coddrop - discard perk
/codskill - class ability (bind v cod_skill)
/codtop - rankings
/codaccess - class access
/codtime - remaining map time

Everyone has double jump; class bonuses stack. No fall damage. Wall cling: knife + hold E; WASD moves, Space jumps away. Jetpack: ground-only CTRL + SPACE. Ninja requires Super VIP. Maps last 45 minutes, then vote for next map or +15 minutes.
