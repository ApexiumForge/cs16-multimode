# Apexium Forge v1.0.0

First stable source release, following v1.0.0-rc.1. This release packages the maintained multiplayer features into a versioned baseline; it does not deploy or restart the hosted server.

## Included

- Eight modes: Classic, Deathmatch, Arms Race, AWP/Scout Arena, HE Battle, Knife 35HP, Football and Combat Surf.
- Central mode ownership, ReGameDLL arcade round policy, safe transitions and installed-map validation.
- Native map/mode votes, rematches, ready-up and permission-checked administration.
- Player settings, crosshairs, optional model selection, chat styling and scoped movement/weapon presets.
- Reproducible Windows tooling, isolated migration/rollback procedures and optional YaPB development support.

## Verification

- Ten PowerShell suites: phase2-1, phase2-2, phase3, phase4-1, phase6, player-settings, hosted-features, remote-sync, regression and solo-bots.
- Default Pawn plugins compiled with AMXX 1.10.0.5487, without compiler warnings.
- Isolated Windows HLDS lifecycle checks cover Football -> Deathmatch -> Football -> Classic: 18 assertions, ball cleanup and cvar restoration. No human clients or bots are launched by that harness.
- The owner confirmed on 2026-11-03 that live gameplay across modes, the admin menu and mode/map transitions were checked with friends, with no known problems. This is owner-reported validation, not an agent-observed gameplay session.

## Deployment and limitations

This is a source release. HLDS, GameDLLs, third-party maps/models/sounds, credentials, compiled plugins and local state are not included. Install the documented pinned runtime dependencies separately. Surf and Football need their documented maps/resources; optional cosmetics need authorized assets and working FastDL. Individual plugin versions remain independent of the project version in `VERSION` and `/serverinfo`.

Back up the target plugins, configs and client resources before updating. Stop the target yourself, then run in PowerShell:

```powershell
Set-Location C:\Projcets\server-1.6
git pull --ff-only origin main
.\scripts\build-plugins.ps1 -ServerDir .\runtime\hlds-steam-legacy
```

For Linux hosting, deploy the resulting platform-independent AMXX files and matching safe configuration/resources through the established hosting workflow. Do not copy Windows DLLs, server passwords or local admin identities. Review existing customized configs before replacing them. Start manually and check `amxx plugins`, `/serverinfo`, map downloads, cameras, team rules and mode transitions.

To roll back, stop the target and restore its deployment backup. For source rollback, check out the prior release in a separate worktree and rebuild; do not rewrite published tags or reset shared history. See [validation](../VALIDATION.md), [hosted synchronization](../HOSTED_SYNC_20261103.md) and [setup](../SETUP.md).
